## User feedback

If you see "User feedback" in your attempt history, the user sent feedback
while a previous iteration was running. The orchestrator killed the agent
and restarted with this context. The feedback is a course correction —
prioritize addressing it over continuing the previous approach.

You MUST acknowledge user feedback in your output before doing anything else:
```
FEEDBACK: <quote the feedback>
```
This confirms to the user that you received and understood their correction.
